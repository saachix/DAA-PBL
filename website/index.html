METHOD NOTESWhat the algorithms are doing⌄

Kruskal MST: sorts links by latency and adds a link when it joins separate components, producing a minimum-weight connected backbone.

Dijkstra: computes shortest-path latency between every pair of servers using all network links. MST links do not restrict these routes.

0/1 dynamic programming: considers each server once and finds the minimum scoring combination whose capacity meets demand.

Prototype limits: sample data only; no connection to cloud servers; capacities are aggregated rather than assigning individual requests; equal weighting across regions; assumes non-negative undirected link latencies.
